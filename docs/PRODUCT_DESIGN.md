# 社媒数据智能分析与生成助手 — 产品设计文档

## 1. 产品定位

面向电商运营、内容运营和品牌团队，解决小红书、抖音等平台“数据分散、分析靠人工、内容产出效率低”的问题。产品将社媒公开内容的采集/导入、清洗、AI 分析与内容生成串成一条自动化工作流，帮助团队从“刷内容凭感觉”转向“看数据做决策”。

## 2. 整体方向

产品采用“数据层 + AI 分析层 + 内容生成层”的三段式结构：

1. 数据层：负责本地样例导入和后续真实采集，完成清洗、去重、入库。
2. AI 分析层：使用 LangGraph 编排帖子摘要、评论情感分析、主题提取和关键洞察。
3. 内容生成层：基于分析结果生成周报、选题建议和可复用文案，输出 Markdown / HTML / JSON。

整体以 API 为主提供服务，后续可继续叠加 Web 看板和定时任务。

## 3. 核心用户场景

- 运营每天查看平台热门内容和评论，手工记录选题。
- 客服或内容团队需要快速了解用户反馈情绪和核心诉求。
- 团队需要每周沉淀一份内容分析周报，供选品和选题决策使用。
- 内容创作者希望从历史数据中提取可复用的文案和选题灵感。

## 4. 主要功能模块

### 4.1 数据源管理

- 支持本地 CSV 样例数据导入，当前覆盖小红书、抖音两种平台格式。
- 预留 MediaCrawler / Playwright 采集扩展点。
- 合规约束：只处理公开数据，不提供绕过登录、风控或批量抓取能力。

### 4.2 数据处理与存储

- 字段标准化：平台、帖子、作者、发布时间、互动指标、标签。
- 数据清洗：去重、缺失值处理、时间解析。
- 结构化入库：PostgreSQL / SQLite + SQLModel。
- 查询能力：支持按平台、时间范围分页查询。

### 4.3 AI 智能分析

- 帖子自动摘要。
- 评论情感分析。
- 主题与关键词提取。
- 趋势洞察汇总。
- 分析过程由 LangGraph 编排，便于后续增加节点和人工介入。

### 4.4 内容生成

- 自动生成分析周报。
- 输出 Markdown、HTML、JSON 三种格式。
- 报告落地为文件并可通过 API 下载。
- Prompt 模板统一管理，便于持续优化。

### 4.5 平台服务与管理

- API Key 鉴权。
- 健康检查。
- 结构化日志与错误记录。
- 定时任务预留（周报自动生成）。
- Docker Compose 一键部署。

## 5. MVP 边界

当前版本不包含：

- 前端 Web 看板。
- 真实 MediaCrawler 采集链路。
- RAG 知识库问答。
- 复杂的用户体系、多租户和计费。

这些内容放在后续迭代中。

## 6. 版本规划

### V1（已完成）

- 本地样例数据导入与清洗。
- LangGraph AI 分析。
- 周报生成与下载。
- API 文档和 Docker 部署。

### V2（建议）

- 接入真实采集源并建设任务监控。
- Web 看板展示数据和报告。
- 定时任务自动生成周报。
- Agent 对话与 RAG 问答。

### V3（可选）

- 多账号 / 多团队。
- 数据报表导出增强。
- 模型评测与 Prompt 版本管理。
- 可观测性与告警。

## 7. 技术方向

- Python 3.11
- FastAPI
- LangGraph / LangChain
- SQLModel + PostgreSQL/pgvector
- MediaCrawler / Playwright
- APScheduler
- Docker Compose

## 8. 成功指标

- 从导入数据到生成周报的完整流程时间。
- 分析结果准确率：情感判断、主题归属。
- 报告可直接使用率：团队是否愿意直接采用选题建议。
- 自动化覆盖场景数：取代人工整理数据的环节数量。
